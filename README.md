## 🌟 Featured Engineering Projects

### 🌊 1. [VIBE — Web3 Hybrid Social Micro-Tipping & Deflationary Rewards](https://github.com/alvinmjosan/VIBE)
> **A high-throughput Web3 social tipping engine bridging zero-gas off-chain custodial processing with deflationary ERC-20 smart contracts.**

- **Architecture**: Spring Boot 3, React 19, Ethers v6, PostgreSQL, Redis, Hardhat (Solidity 0.8.20).
- **Key Innovations**:
  - **Web3 Signature Authentication**: Cryptographic nonce challenge verification (`personal_sign`) via MetaMask.
  - **Off-Chain Gasless Engine**: Double-entry custodial ledger handling instant micro-tips with zero blockchain gas fees.
  - **Deflationary Tokenomics (`VibeToken.sol`)**: ERC-20 token featuring a 0.5% burn tax on peer transfers, with `MINTER_ROLE` exemptions for untaxed reward claims.
  - **Dual-Wallet Binding**: Decoupled Signing Wallets (identity) and Claim Wallets (target on-chain address).

### 📦 2. [SmartShelfX — AI-Based Inventory Forecast & Auto-Restock](https://github.com/alvinmjosan/SmartShelfX-AI-Based-Inventory-Forecast-Auto-Restock)
> **An intelligent supply-chain management platform using predictive analytics to forecast demand and automate stock replenishment.**

- **Architecture**: Java 17, Spring Boot 3.3, React 19, MySQL, Chart.js, Spring Security.
- **Key Innovations**:
  - **Predictive Demand Forecasting**: AI/ML time-series algorithms analyzing historical data to predict stock shortages.
  - **Automated Replenishment**: Trigger rules and real-time alert notifications when stock levels fall below critical thresholds.
  - **Interactive Analytics Dashboard**: Visual stock health tracking built with Chart.js and React.

### 📊 3. [Finance Dashboard — Enterprise Financial Analytics Platform](https://github.com/alvinmjosan/finance_dashboard)
> **A modern financial analytics platform providing real-time data visualization and persistent budget management.**

- **Architecture**: Next.js 16 (App Router), React 19, TypeScript, Redux Toolkit, Redux Persist, Recharts, Framer Motion.
- **Key Innovations**:
  - **Persistent State Architecture**: Redux Toolkit & `redux-persist` ensuring seamless offline state synchronization.
  - **Interactive Financial Visualizations**: Custom Recharts components for income/expense trends and portfolio distributions.
  - **Fluid UX**: Animated UI transitions leveraging Framer Motion micro-interactions.

### 🍔 4. [College Canteen — Campus Ordering & Inventory System](https://github.com/alvinmjosan/college-canteen)
> **A full-stack food ordering and canteen management system for campus environments.**

- **Architecture**: Node.js, Express.js, React 19 (Vite), MongoDB, Mongoose, Nodemailer, JWT.
- **Key Innovations**:
